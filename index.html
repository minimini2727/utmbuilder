※ 빌더의 '예상 채널'은 GA4 기본 채널 그룹 규칙을 단순화해 구현한 추정치입니다. Google이 관리하는 소스 카테고리 목록은 수시로 갱신되므로, 실제 분류는 GA4 실시간 보고서에서 한 번 확인하는 것을 권장합니다.

3. 네이밍 규칙 권장

  • GA4는 대소문자를 구분합니다 — Naver와 naver는 다른 소스로 집계됩니다. 소문자로 통일하세요.
  • 공백 대신 언더스코어(_)를 사용합니다. 공백은 인코딩되어 + 또는 %20으로 남습니다.
  • 한글 값은 가능하지만 URL이 길어지고 다른 툴에서 깨질 수 있어, source/medium/campaign은 영문 권장 / term(키워드)만 한글 허용 등 팀 규칙을 정해두세요.
  • 캠페인명은 기간_브랜드_목적_구분처럼 고정 순서를 정하면 GA4 탐색 분석에서 필터링이 쉬워집니다.

4. 매체별 주의사항

  • Google Ads: 자동 태그 추가(gclid) 사용 시 GA4는 기본적으로 자동 태그 값을 우선 적용합니다. 수동 UTM은 Google Ads 외 매체 위주로 사용하세요.
  • 네이버 검색광고: 키워드 단위 추적이 필요하면 utm_term에 키워드를 넣거나 매체 자체 추적 파라미터와 병행합니다.
  • Meta: 광고 관리자 'URL 매개변수' 영역에 {{campaign.name}} 같은 동적 매크로를 넣으면 소재별 자동 태깅이 가능합니다. 빌더에서 매크로를 그대로 입력하려면 '소문자 자동 변환'을 끄세요.
  • 카카오/네이버 GFA: 소스를 kakao / naver로 두고 medium을 display로 지정하면 Display 채널로 분류됩니다.

5. 운영 체크리스트

  • 집행 전: 생성 URL을 새 탭에서 열어 랜딩·리디렉션 후에도 UTM이 유지되는지 확인
  • 집행 직후: GA4 → 실시간 보고서에서 소스/매체가 의도대로 찍히는지 확인
  • 주 1회: 관리 탭에서 종료된 캠페인 상태 업데이트, CSV 백업
