P.P마다 해결해 줄 USP를 고르면 [USP 번호]-[P.P 번호]로 짝지어져요 (예: 1-1, 2-2). VP는 이 매칭 쌍마다 1개씩 만들어져요.
AI 모드는 내 Claude API 키로 브라우저에서 직접 호출해요. 키는 이 브라우저(localStorage)에만 저장되고 서버로 보내지지 않아요. 공용 PC에서는 사용 후 키를 지워주세요.
작성 가이드 — VP는 이렇게 만들어져요
  • VP(Value Proposition) = 타겟의 Pain Point를 브랜드 USP로 해결해 주는 약속
  • VP는 단어를 이어 붙이지 않고, 해결된 상태를 부를 수 있는 컨셉 이름으로 만들어요 (예: 새벽배송 + 늦은 택배 불편함 = 슈팅배송)
  • P.P마다 매칭한 USP와 짝지어(1-1, 2-2 …) 쌍마다 VP를 1개씩 만들고, 1개를 골라 컨셉 카피 10개로 확장
  • 카피는 메인 15자·서브 20자 이내를 목표로(내부 권장값) 소구 각도를 모두 다르게 구성해 A/B 테스트에 바로 쓰기 좋게 했어요
  • 카드의 메인/서브 카피는 클릭해서 바로 수정할 수 있어요
